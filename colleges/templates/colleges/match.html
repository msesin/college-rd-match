Match

The matching engine scores how well each student matches each college: the student match %. It is not a chance of admission: a perfect match can still be turned down, especially with a request for full financial aid. The preliminary match is computed when a student submits; then the crowding cut (UGS applicants against the college's UGS capacity, up to −{{ crowding.cut }}%) is applied from the current lists, so the final match changes live as lists change. Students see only the final %, and their {{ top_n }} best matches straight away. {{ n_submitted }} of {{ n_students }} students have submitted their form. How it works: docs/algorithm.md.
